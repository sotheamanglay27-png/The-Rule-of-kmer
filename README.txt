RULE KHMER SURVIVAL 3D — Prototype

How to use:
1. Extract the ZIP.
2. Open index.html in a browser with internet access (Three.js is loaded from jsDelivr CDN).
3. On Android, Chrome is recommended.
4. For a public website, upload the whole folder to a static hosting service such as GitHub Pages, Netlify, or Cloudflare Pages.

Included:
- Interactive 3D Angkor-inspired scene (procedurally generated)
- Drag-to-rotate scene and auto-rotation toggle
- Skin selection UI, guest demo login, start button
- Reference images in /assets

Limitations:
This is a visual website prototype, not the actual ROS/Rules Survival game. It does not connect to official game accounts, grant real skins, or run multiplayer gameplay.
